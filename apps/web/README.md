# @clearspec/web

The hosted app on Cloudflare (Worker + Durable Objects): public landing page, GitHub sign-in, and runs on the user's own computer through `clearspec connect`.

## Planned

- Landing page with a demo video and sample specs from `examples/`, viewable without signing in.
- Mockups served from a separate, sandboxed origin.
- Export a spec as a zip or a GitHub PR.
- Retention limits and a delete button for runs.
- A real domain instead of `*.workers.dev`.
